2. Architecture & Runtime Choice

Mocha Topia is a client-side frontend website constructed with HTML5, CSS3, JavaScript (ES6), and jQuery. Because it does not require server-side compilation, choosing Nginx on Alpine Linux provides the most efficient and secure runtime:

Runtime Image Footprint Security Profile Evaluation
Ubuntu + Node.js ~500 MB Large attack surface, extra tools ❌ Excessive overhead
Node.js Alpine ~180 MB Medium, unnecessary JS engine ❌ Unneeded runtime
Nginx 1.27 Alpine (Selected) 77.9 MB Minimal, secure, purpose-built HTTP ✅ Optimal Choice

6. Configuration Code Artifacts

Dockerfile

FROM nginx:1.27-alpine
WORKDIR /usr/share/nginx/html
RUN rm -rf ./*
COPY . .
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

compose.yaml

services:
  app:
    build: .
    container_name: mocha-topia-app
    ports:
      - "8080:80"
    restart: unless-stopped
